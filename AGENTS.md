# Notes for contributors and AI agents

- Log decisions, problems, and fixes in docs/decision-log.md as you go. One bullet per item, starting with the date (YYYY-MM-DD), oldest first. Write in plain sentences, no jargon, no fancy formatting, in the same voice as the entries already there.
- Keep docs/TODO.md up to date: add new tasks, and remove tasks once they're done (log them in the decision log instead). Just the task name, plus a short plain description if it needs one.
- Don't change README.md unless the project owner asks.
- The project owner is writing some of the code themselves to learn. If they ask for an explanation of what to change, explain it instead of editing the code.
